# Транслятор учебного конфигурационного языка в XML (вариант №19)

## Общее описание

Инструмент командной строки преобразует текст на учебном конфигурационном
языке в XML. Реализован на Python 3 без внешних зависимостей. Входной и
выходной файлы задаются ключами командной строки. Синтаксические ошибки
выводятся с номером строки и столбца.

## Запуск

```bash
python3 src/main.py -i examples/web_server.conf -o web_server.xml
make test
make examples
```

| Ключ | Описание |
|---|---|
| `-i`, `--input` | путь к входному файлу (обязательно) |
| `-o`, `--output` | путь к выходному XML-файлу (обязательно) |

Коды завершения: 0 — успех, 1 — ошибка в тексте конфигурации или при
работе с файлами (выходной файл при этом не создаётся), 2 — ошибка ключей.

## Синтаксис языка

| Конструкция | Запись | Пример |
|---|---|---|
| Однострочный комментарий | `'` до конца строки | `' комментарий` |
| Многострочный комментарий | `{` ... `}` | `{ текст }` |
| Число | `0[bB][01]+` | `0b1010` |
| Строка | `q(` текст `)` | `q(Это строка)` |
| Массив | `[` значения через `;` `]` | `[0b1; q(a); [0b10]]` |
| Имя | `[a-zA-Z][a-zA-Z0-9]*` | `maxSize` |
| Константа | `set имя = значение` | `set a = 0b101` |
| Выражение | `$` выражение `$` | `$a + 0b1$` |

Значением может быть число, строка, массив или выражение. Выражения
поддерживают `+`, `-`, `*`, скобки и функции `sqrt(x)` и `min(a; b; ...)`.
Аргументы функций разделяются `;`. В выражениях можно использовать ранее
заданные константы. Значение вне `set` тоже допустимо и попадает в XML без
имени.

Ограничения: константу нельзя объявить повторно, имена `set`, `sqrt` и `min`
зарезервированы, `sqrt` возвращает целую часть корня, строка заканчивается
на первой `)`, многострочные комментарии не вкладываются.

## Формат XML

Корень `<config>`. Константа записывается как `<constant name="...">`, внутри
значение: `<number>` (десятичная запись), `<string>` или `<array>` с вложенными
элементами.

## Примеры

Три конфигурации из разных предметных областей лежат в `examples/`:

| Файл | Область | Что показывает |
|---|---|---|
| `web_server.conf` | веб-сервер | комментарии, строки, массивы, `min`, умножение |
| `game_level.conf` | игра | вложенные массивы, выражения в массиве, `sqrt`, `min` |
| `pendulum_lab.conf` | лаборатория | вычитание, вложенный массив строк, `min` из трёх |

Результат для `web_server.conf`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<config>
  <constant name="serverName">
    <string>example server</string>
  </constant>
  <constant name="port">
    <number>80</number>
  </constant>
  <constant name="workers">
    <number>4</number>
  </constant>
  <constant name="maxConnections">
    <number>800</number>
  </constant>
  <constant name="allowedHosts">
    <array>
      <string>localhost</string>
      <string>example.org</string>
      <string>www.example.org</string>
    </array>
  </constant>
  <constant name="timeouts">
    <array>
      <number>10</number>
      <number>30</number>
      <number>20</number>
    </array>
  </constant>
</config>
```

Ошибки:

```
ошибка: строка 2, столбец 14: константа 'c' не задана
ошибка: строка 1, столбец 18: некорректное число '0b12': ожидается 0b или 0B и двоичные цифры
ошибка: строка 1, столбец 1: незакрытый многострочный комментарий
```

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/main.py` | ключи командной строки, чтение и запись файлов, коды завершения |
| `src/lexer.py` | разбиение текста на лексемы, пропуск комментариев |
| `src/syntax.py` | разбор грамматики и вычисление констант и выражений |
| `src/xml_writer.py` | построение XML |
| `src/errors.py` | класс ошибки трансляции |
| `tests/` | модульные тесты (`unittest`) |
| `examples/` | три примера конфигураций |
| `Makefile` | запуск тестов и примеров |
